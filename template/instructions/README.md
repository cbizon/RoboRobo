# Instructions

One file per day, `YYYY-MM-DD.md`, written by the daily debrief after the
scientist approves it. A session uses the file dated today, or
`fallback.md` if there isn't one. Old instructions stay as the record of how
the program was steered.

Each instruction has two sections:

- `## Asked`: a numbered list of what the scientist asked for, in the
  scientist's own words. The session answers each item as it was asked, and
  the checker and the next debrief hold it to that wording.
- `## Details`: how to carry the items out, written by the debrief for the
  agent. Details add to what was asked; they don't narrow it.
